# Exemplos de lançamentos contábeis

Lançamentos (débito e crédito) para as situações mais comuns, com a norma que manda fazer assim. Os valores são ilustrativos e os nomes de conta são genéricos: adapte ao seu plano de contas. Tributos sobre a folha, PIS/COFINS e outros detalhes fiscais foram simplificados de propósito.

| Arquivo | Situações |
|---|---|
| [estoques-e-custos.md](estoques-e-custos.md) | compra de insumos com créditos de ICMS/IPI, ociosidade, ajuste ao VRL, venda com CMV |
| [imobilizado-e-arrendamentos.md](imobilizado-e-arrendamentos.md) | compra de máquina, depreciação na produção, aluguel pela NBC TG 06, impairment |
| [receitas.md](receitas.md) | venda com devolução esperada, marketplace como agente, pontos de fidelidade, venda a prazo com juros, garantia |
| [tributos-e-subvencoes.md](tributos-e-subvencoes.md) | IR diferido, crédito presumido de ICMS e reserva de incentivos, IBS/CBS com split payment |
| [pessoal-e-provisoes.md](pessoal-e-provisoes.md) | férias, PLR, processo trabalhista |
| [instrumentos-financeiros-e-cambio.md](instrumentos-financeiros-e-cambio.md) | perda esperada de clientes, antecipação de recebíveis, variação cambial de fornecedor |
| [agro.md](agro.md) | valorização de rebanho, colheita |
| [bancos.md](bancos.md) | instituições financeiras: provisão por estágios, ativo problemático, baixa a prejuízo, renegociação (Res. CMN 4.966) |
