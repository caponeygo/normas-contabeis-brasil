# Lançamentos: pessoal e provisões

Normas: NBC TG 33 (benefícios a empregados), NBC TG 25 (provisões). Ver [Servicos/03-pessoal-e-beneficios.md](../Servicos/03-pessoal-e-beneficios.md).

## 1. Provisão mensal de férias

Salário de R$ 5.000. Cada mês trabalhado dá 1/12 de férias mais o adicional de 1/3: (5.000 + 1.666,67) ÷ 12 = R$ 555,56, mais encargos (INSS patronal, FGTS etc., conforme o regime da empresa).

| | Conta | Valor |
|---|---|---|
| D | Despesa (ou custo) com férias | 555,56 |
| C | Provisão para férias | 555,56 |
| D | Despesa (ou custo) com encargos sobre férias | (encargos) |
| C | Provisão de encargos sobre férias | (encargos) |

Por quê: ausências remuneradas acumuláveis são reconhecidas à medida que o empregado adquire o direito (NBC TG 33, itens 13–15). O 13º salário segue a mesma lógica mensal (item 11).

## 2. Participação nos lucros (PLR)

Acordo coletivo prevê PLR; metas do ano indicam pagamento estimado de R$ 120.000. Provisão proporcional no trimestre: R$ 30.000.

| | Conta | Valor |
|---|---|---|
| D | Despesa com participação nos lucros | 30.000 |
| C | Participação nos lucros a pagar | 30.000 |

Por quê: provisionar quando há obrigação presente (acordo ou prática) e o valor é estimável (NBC TG 33, itens 19–24).

## 3. Processo trabalhista com perda provável

Advogados avaliam a perda como provável, estimada em R$ 50.000.

| | Conta | Valor |
|---|---|---|
| D | Despesa com provisões para contingências | 50.000 |
| C | Provisão para contingências trabalhistas | 50.000 |

Por quê: obrigação presente, saída de recursos provável e estimativa confiável (NBC TG 25, item 14). Perda possível: só nota explicativa; remota: nada.
