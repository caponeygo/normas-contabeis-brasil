# Lançamentos: receitas

Norma principal: NBC TG 47 (CPC 47, IFRS 15). Ver [areas/receitas.md](../areas/receitas.md) e [Varejo/02-vendas-e-receita.md](../setores/varejo/02-vendas-e-receita.md).

## 1. Venda com direito de devolução

100 unidades a R$ 50 (R$ 5.000); histórico indica 5% de devolução; custo R$ 30 por unidade.

| | Conta | Valor |
|---|---|---|
| D | Clientes | 5.000 |
| C | Receita de vendas | 4.750 |
| C | Passivo de reembolso (devoluções esperadas) | 250 |
| D | Custo das vendas | 2.850 |
| D | Direito de recuperar produtos devolvidos (ativo) | 150 |
| C | Estoque | 3.000 |

Por quê: receita só pelo que se espera não devolver (NBC TG 47, itens B20–B27).

## 2. Marketplace que atua como agente

Cliente paga R$ 1.000 por produto de um vendedor parceiro; a comissão do marketplace é de 15%.

| | Conta | Valor |
|---|---|---|
| D | Caixa / recebíveis | 1.000 |
| C | Receita de comissões | 150 |
| C | Contas a pagar a vendedores parceiros | 850 |

Por quê: quem não controla o produto antes da venda é agente e reconhece só a comissão (NBC TG 47, itens B34–B38).

## 3. Venda com pontos de fidelidade

Venda de R$ 1.000 que dá pontos. Preço de venda individual: produto R$ 1.000; pontos R$ 50 (já considerando a probabilidade de uso). Alocação pelo preço relativo: produto R$ 952, pontos R$ 48.

| | Conta | Valor |
|---|---|---|
| D | Caixa | 1.000 |
| C | Receita de vendas | 952 |
| C | Passivo de contrato – programa de fidelidade | 48 |

Quando os pontos forem usados (ou expirarem):

| | Conta | Valor |
|---|---|---|
| D | Passivo de contrato – programa de fidelidade | 48 |
| C | Receita de vendas | 48 |

Por quê: pontos que dão direito material ao cliente são obrigação de desempenho separada (NBC TG 47, itens B39–B43).

## 4. Venda a prazo com juros embutidos

Preço à vista R$ 9.000; vendido por R$ 10.000 em 12 parcelas.

| | Conta | Valor |
|---|---|---|
| D | Clientes | 10.000 |
| C | Receita de vendas | 9.000 |
| C | Juros a apropriar (redutora de clientes) | 1.000 |

Mensalmente, pela taxa efetiva:

| | Conta | Valor |
|---|---|---|
| D | Juros a apropriar | (parcela do mês) |
| C | Receita financeira | (parcela do mês) |

Por quê: componente de financiamento separado da receita (NBC TG 47, itens 60–65) e ajuste a valor presente (NBC TG 12). No Brasil não há a dispensa de prazos até 1 ano.

## 5. Provisão de garantia de produto

Vendas do mês R$ 200.000; histórico de gastos com garantia de 2%.

| | Conta | Valor |
|---|---|---|
| D | Despesa com garantias | 4.000 |
| C | Provisão para garantias | 4.000 |

Quando houver reparo coberto:

| | Conta | Valor |
|---|---|---|
| D | Provisão para garantias | (custo do reparo) |
| C | Estoque de peças / Caixa | (custo do reparo) |

Por quê: garantia que só assegura o funcionamento do produto é provisão (NBC TG 47, itens B28–B33; NBC TG 25, itens 14, 24 e 39). Garantia estendida vendida à parte vira receita diferida.
