# Comércio e Varejo: normas que importam

Trechos das normas que importam para atacado, varejo, e-commerce e distribuidores: da compra da mercadoria até a venda no caixa ou no site, passando por loja alugada, cartões e tributos.

> Resumo orientativo dos trechos das normas aplicáveis ao setor; não substitui o texto oficial. Os números de item seguem o CPC/NBC (mesma numeração da IAS/IFRS) e são conferidos automaticamente contra os PDFs oficiais (`verificacao/CONTEUDO.md`). Confira sempre pelo link oficial.

## Perguntas frequentes

| Pergunta | Resposta curta | Norma (item) |
|---|---|---|
| Bonificação recebida do fornecedor é receita? | Não; reduz o custo da mercadoria. | [NBC TG 16 (R2)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG16(R2)&arquivo=NBCTG16(R2).doc) (item 11) |
| ICMS-ST pago na compra entra no custo? | Sim, quando não há direito a crédito. | [NBC TG 16 (R2)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG16(R2)&arquivo=NBCTG16(R2).doc) (item 11) |
| Furto e quebra de estoque vão para onde? | Despesa do período em que ocorrem. | [NBC TG 16 (R2)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG16(R2)&arquivo=NBCTG16(R2).doc) (item 34) |
| Posso usar o método de varejo? | Sim, se o resultado se aproximar do custo. | [NBC TG 16 (R2)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG16(R2)&arquivo=NBCTG16(R2).doc) (item 21) |
| No marketplace, a receita é o valor total da venda? | Só se a empresa for principal; se for agente, só a comissão. | [NBC TG 47](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2016/NBCTG47&arquivo=NBCTG47.doc) (itens B34–B38) |
| Pontos de fidelidade viram receita quando? | Quando usados ou expirados; até lá, receita diferida. | [NBC TG 47](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2016/NBCTG47&arquivo=NBCTG47.doc) (itens B39–B43) |
| Vale-presente não usado vira receita? | Sim, a parte que se espera nunca ser usada, proporcionalmente ao uso. | [NBC TG 47](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2016/NBCTG47&arquivo=NBCTG47.doc) (itens B44–B47) |
| Antecipação de recebíveis de cartão baixa o recebível? | Só se transferir substancialmente riscos e benefícios. | [NBC TG 48](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2016/NBCTG48&arquivo=NBCTG48.doc) (item 3.2.6) |
| Aluguel sobre % das vendas entra no passivo de arrendamento? | Não; é despesa do período. | [NBC TG 06 (R3)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG06(R3)&arquivo=NBCTG06(R3).doc) (item 38) |
| Cada loja é testada para impairment separadamente? | Em geral sim: cada loja costuma ser uma UGC. | [NBC TG 01 (R4)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG01(R4)&arquivo=NBCTG01(R4).doc) (itens 66–73) |
