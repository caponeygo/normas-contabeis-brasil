# Agronegócio: normas que importam

Trechos das normas que importam para produtores rurais, usinas, cooperativas agropecuárias, frigoríficos com criação própria e empresas florestais: do ativo biológico na fazenda até o produto colhido no estoque.

> Resumo orientativo dos trechos das normas aplicáveis ao setor; não substitui o texto oficial. Os números de item seguem o CPC/NBC (mesma numeração da IAS/IFRS) e são conferidos automaticamente contra os PDFs oficiais (`verificacao/CONTEUDO.md`). Confira sempre pelo link oficial.

## Perguntas frequentes

| Pergunta | Resposta curta | Norma (item) |
|---|---|---|
| Gado em engorda fica a custo ou valor justo? | Valor justo menos despesa de venda, com a variação no resultado. | [NBC TG 29 (R2)](https://www1.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/NBCTG29(R2)) (item 12) |
| Pé de café é ativo biológico? | Não; é planta portadora, vai para o imobilizado. O café que cresce nele é ativo biológico. | [NBC TG 29 (R2)](https://www1.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/NBCTG29(R2)) (item 2) |
| Eucalipto para madeira é planta portadora? | Não; árvore cultivada para ser colhida como produto segue a NBC TG 29. | [NBC TG 29 (R2)](https://www1.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/NBCTG29(R2)) (item 5A) |
| Grão colhido entra no estoque por quanto? | Valor justo menos despesa de venda na colheita. | [NBC TG 16 (R2)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG16(R2)&arquivo=NBCTG16(R2).doc) (item 20) |
| E se não der para medir o valor justo? | Custo menos depreciação e perdas, até ser mensurável. | [NBC TG 29 (R2)](https://www1.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/NBCTG29(R2)) (itens 30–33) |
| Terra se deprecia? | Em geral não. | [NBC TG 27 (R4)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG27(R4)&arquivo=NBCTG27(R4)_rev18.doc) (item 58) |
| Juros do Plano Safra abaixo do mercado têm efeito contábil? | Sim: a diferença para o valor justo é subvenção. | [NBC TG 07 (R2)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/NBCTG07(R2)&arquivo=NBCTG07(R2).doc) (item 10A) |
| Venda futura da safra é derivativo? | Não, se for para entrega física da própria produção (uso próprio). | [NBC TG 48](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2016/NBCTG48&arquivo=NBCTG48.doc) (item 2.4) |
