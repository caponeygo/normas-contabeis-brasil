Normas Contábeis · Mapa por área

Cada bolinha é uma norma (as maiores, com contorno, são as áreas), todas num círculo só, agrupadas por área. As cores separam as séries: NBC TG/CPC, setor público, auditoria, IFRS etc. Passe o mouse para ver as ligações, clique para fixar, arraste uma bolinha para puxá-la pelo círculo e use a roda do mouse para o zoom: quanto mais perto, mais nomes aparecem.
Passe o mouse em uma bolinha para ver o que ela é e com quem se liga.
roda do mouse: zoom · arrastar o fundo: mover
