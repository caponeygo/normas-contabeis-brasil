# Terceiro Setor: normas que importam

Trechos das normas que importam para entidades sem finalidade de lucros (associações, fundações, institutos, entidades de saúde, educação e assistência social), cooperativas e partidos políticos.

> Resumo orientativo dos trechos das normas aplicáveis ao setor; não substitui o texto oficial. Os números de item seguem o CPC/NBC (mesma numeração da IAS/IFRS) e são conferidos automaticamente contra os PDFs oficiais (`verificacao/CONTEUDO.md`). Confira sempre pelo link oficial.

## Perguntas frequentes

| Pergunta | Resposta curta | Norma (item) |
|---|---|---|
| Doação recebida vai direto para o patrimônio? | Em regra vai para o resultado (regime de competência); doação patrimonial do instituidor vai para o patrimônio social. | [ITG 2002 (R1)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/ITG2002(R1)&arquivo=ITG2002(R1).doc) (itens 9, 18) |
| Recurso de convênio ainda não aplicado é receita? | Não; fica no passivo até cumprir os requisitos. | [ITG 2002 (R1)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/ITG2002(R1)&arquivo=ITG2002(R1).doc) (itens 11–12) |
| Imunidade tributária vira receita? | Não; não é subvenção. Divulgar a renúncia fiscal. | [ITG 2002 (R1)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/ITG2002(R1)&arquivo=ITG2002(R1).doc) (item 9B) |
| Trabalho voluntário é contabilizado? | Sim, pelo valor justo do serviço. | [ITG 2002 (R1)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/ITG2002(R1)&arquivo=ITG2002(R1).doc) (item 19) |
| Como se chama o lucro de uma ONG? | Superávit (ou déficit), incorporado ao patrimônio social. | [ITG 2002 (R1)](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2015/ITG2002(R1)&arquivo=ITG2002(R1).doc) (itens 15, 23) |
| Quota de cooperado que saiu continua no PL? | Não; vai para capital a restituir no passivo. | [ITG 2004](https://www2.cfc.org.br/sisweb/sre/detalhes_sre.aspx?Codigo=2017/ITG2004&arquivo=ITG2004.doc) (item 19) |
| Partido político segue qual norma? | NBC TPE 01, obrigatória a partir das eleições de 2026. | [OT CFC 02/2026](https://cfc.org.br/wp-content/uploads/2026/08/CFC_Orientacao_Tecnica_2.pdf) |
