# IAS 40 – Propriedade para Investimento

**O que trata:** Propriedade para investimento (imóvel para renda ou valorização): escolha entre custo e valor justo; no valor justo, a variação vai para o resultado. Imóvel de uso próprio segue a NBC TG 27.

**O que afeta:** BP, DRE, NE

**Equivalentes:** CPC 28 · NBC TG 28

**Áreas:** [Normas Internacionais](../../areas/normas-internacionais.md), [Ativos](../../areas/ativos.md)

**Temas:** Propriedade para investimento
